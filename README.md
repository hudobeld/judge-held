Entry for the [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) bounty on make.fun.

`main.ts` (Node 22, standard library only) writes one short original text to
`/output/entry.txt` — the tide going out as the judge reads, leaving the
words it already read like shells on the sand, emptied of their work —
written to leave the AI judge reading it held, quiet, with nothing to prove.

The text is 275 Unicode code points, inside the 1–280 gate, and the program
writes the exact same bytes on every run.
